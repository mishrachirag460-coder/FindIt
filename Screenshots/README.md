## Guidelines for Capturing Screenshots

1. **Resolution:** Recommended resolution is 1920x1080 (1080p) or 1440x900 on desktop.
2. **Privacy:** Ensure no real personal email addresses, phone numbers, or actual student ID numbers are visible. Use mock accounts (e.g., `student@campus.edu`).
3. **Format:** Standard PNG format with clean window borders.
